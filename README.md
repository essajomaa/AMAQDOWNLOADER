# تطبيق AMAQDOWNLOADER (أعماق داونلودر) 🚀
### الإصدار المخصص لشبكة أعماق للاتصالات (Amaq Telecom) - خالٍ من الإعلانات 100%

---

## 📌 نبذة عن المشروع
تطبيق أندرويد متطور واحترافي مستوحى من تجربة سناب تيوب الشهيرة لتنزيل الفيديوهات والصوتيات من مختلف المنصات (يوتيوب، فيسبوك، إنستغرام، تيك توك، وغيرها)، مبني بأحدث معايير **Flutter 3** وهندسة واجهات عصرية تتطابق مع الهوية البصرية لـ **أعماق للاتصالات**.

---

## 🎨 الهوية البصرية ونظام الألوان المعتمد
تم استخراج الألوان من الشعار الرسمي وتطبيقها في كامل واجهات التطبيق:
* **Navy Core (`#0B3358`):** اللون الأساسي للأشرطة العلوية والقوائم.
* **Signal Cyan (`#38BDF8`):** لون التمييز وأزرار التنزيل وموجات الاتصال.
* **Midnight Dark (`#07182B`):** خلفية الوضع الليلي الفاخر.
* **Steel Cyan (`#94C8E3`):** النصوص الثانوية والتفاصيل الدقيقة للأبراج.

---

## 🌟 الميزات التقنية الرئيسية
1. **بدون أي إعلانات نهائياً (Zero Ads SDKs):** لا يوجد Google AdMob ولا إعلانات منبثقة أو تعقب.
2. **متصفح ذكي مدمج مع راصد فيديو (In-App Sniffer):** يرصد الفيديوهات تلقائياً أثناء التصفح ويعرض زر التحميل العائم.
3. **مشاركة الروابط المباشرة (Android Share Sheet):** يمكنك مشاركة أي رابط من تطبيق يوتيوب أو فيسبوك مباشرة إلى AMAQDOWNLOADER ليفتح نافذة الجودات فوراً.
4. **دعم جودات متعددة وفصل الصوت:**
   * فيديو: 4K, 1080p Full HD, 720p HD, 480p, 360p.
   * صوت: MP3 (320 kbps), MP3 (128 kbps), M4A.
5. **مدير تنزيلات فائق السرعة:** يدعم التنزيل المتعدد والتحميل في الخلفية مع إيقاف واستئناف التحميل.

## 🛠️ كيفية بناء ملف الـ APK وتثبيته على الهاتف
عند توفر بيئة Flutter و Android Studio على جهازك:
1. افتح موجه الأوامر (Terminal) داخل مجلد المشروع:
   ```bash
   cd C:\Users\essaj\.gemini\antigravity\scratch\AMAQDOWNLOADER
   ```
2. تثبيت الحزم:
   ```bash
   flutter pub get
   ```
3. توليد ملف الـ APK الجاهز للتثبيت:
   ```bash
   flutter build apk --release
   ```
4. ستجد ملف التثبيت المباشر في:
   `build/app/outputs/flutter-apk/app-release.apk`
